# 스마트 재정청구 (Church Finance Claim) PWA 앱

교회 및 단체 재정부에서 성도와 사역자들이 영수증 사진을 찍어 손쉽게 재정을 청구하고, 구글 시트와 구글 드라이브에 자동으로 누적 정리되는 웹 애플리케이션입니다.

---

## 🌟 주요 기능
1. **스마트 영수증 촬영 및 인식**: 카메라로 영수증을 촬영하면 자동으로 이미지 압축 및 금액 감지
2. **다건 청구 자동 합산**: 한 번에 여러 건의 영수증을 등록하면 자동으로 총 청구 금액 계산
3. **영수증 없는 항목 직접 입력 지원**: 간이영수증, 계좌이체 등 영수증이 없는 경우에도 직접 입력 청구 가능
4. **구글 시트 & 드라이브 자동 연동**:
   - `청구접수대장` 시트: 접수번호, 청구자, 부서, 계좌, 총금액, 영수증 링크 등 마스터 관리
   - `청구상세항목` 시트: 건별 개별 항목 및 계정과목별 상세 장부 관리
   - `재정부_영수증_보관함` 구글 드라이브 폴더: 영수증 사진 자동 분류 및 보관
5. **PWA 홈 화면(바탕화면) 설치 지원**:
   - 안드로이드(크롬/엣지): 원클릭 '바탕화면에 설치하기' 버튼 지원
   - iOS(아이폰/아이패드 사파리): 안내 팝업을 통한 '홈 화면에 추가' 완벽 가이드
   - standalone 모드 지원으로 네이티브 앱처럼 동작

## 🚀 1. Google Sheets & Apps Script 설정 방법 (5분 소요)

1. [Google 스프레드시트](https://sheets.google.com)에서 **새 스프레드시트**를 생성합니다. (제목 예: `2026 재정부 청구접수대장`)
2. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
3. 프로젝트 안의 기존 `myFunction` 코드를 지우고, 동봉된 **`Code.gs`** 파일의 전체 코드를 복사하여 붙여넣습니다.
4. 우측 상단 **[배포]** 버튼을 누르고 **[새 배포]**를 선택합니다.
5. 설정 톱니바퀴 아이콘을 눌러 **[웹 앱 (Web app)]**을 선택합니다:
   - **설명**: `재정청구 웹앱 API`
   - **다음 사용자 권한으로 실행**: `나(내 Google 계정)`
   - **액세스 권한이 있는 사용자**: `모든 사용자(Anyone)` ⭐️⭐️⭐️ (중요: 성도들이 별도 구글 로그인 없이도 제출할 수 있도록 반드시 '모든 사용자'로 설정해야 합니다)
6. **[배포]**를 누른 뒤 권한 승인 창이 뜨면 계정을 선택하고 허용합니다.
7. 최종 생성된 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사합니다.
8. 재정청구 앱의 **[연동 및 설정]** 탭에 붙여넣고 **'저장 및 연결 테스트'**를 누르면 연동이 완료됩니다!

## 🌐 2. GitHub Pages 무료 배포 방법 (3분 소요)

1. [GitHub](https://github.com)에 로그인 후 새 Repository를 생성합니다 (예: `finance-claim`).
2. 저장소에 아래 파일들을 업로드(또는 git push)합니다:
   - `index.html` (메인 웹앱)
   - `manifest.json` (PWA 매니페스트)
   - `sw.js` (서비스 워커)
   - `icon.png` (앱 아이콘)
3. 저장소의 **[Settings]** 탭으로 이동합니다.
4. 좌측 메뉴에서 **[Pages]**를 클릭합니다.
5. **Build and deployment** 항목의 Source를 `Deploy from a branch`로 두고, Branch를 `main` (또는 `master`) / `/ (root)`로 선택한 후 **[Save]**를 클릭합니다.
6. 1~2분 뒤 나타나는 배포 주소(예: `https://<아이디>.github.io/finance-claim/`)로 접속하면 스마트폰과 PC 어디서나 사용할 수 있습니다!

## 📱 3. 스마트폰 홈 화면(바탕화면)에 설치하기

- **안드로이드 폰 (갤럭시 등)**:
  - 브라우저로 접속 시 첫 화면 상단에 나타나는 **[📲 바탕화면에 설치하기]** 버튼을 터치하면 바로 홈 화면에 앱 아이콘이 추가됩니다.
- **아이폰 / 아이패드**:
  - Safari 브라우저 하단의 **공유 버튼(네모에 위 화살표 [↑])**을 누른 후, 메뉴에서 **'홈 화면에 추가'**를 누르면 앱으로 설치됩니다.
